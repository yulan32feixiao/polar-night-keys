## 一、留下来能反复用的东西

### 1. 游戏本体 `src/极夜落键.html`（单文件，离线可玩）

| 能力 | 说明 |
|---|---|
| 读任何标准 MIDI | 自带解析器，format 0/1、变速、多轨都行；鼓轨自动忽略 |
| 自动分左右手 | 多轨→挑最高的主轨；单轨→每个时刻取最高音当旋律；也可手选某一轨或按 C4 切分 |
| 键位自适应 | 一首歌用到几个音就用几个键。≤10 个音只用中间排；更多时常用音居中排、高音上排、低音下排 |
| 三种模式 | 等待我（停下来等你按对）／跟节奏（只判时机）／照谱弹（键+时机） |
| 左手自动 | 伴奏声部由程序弹 |
| 曲库 | 拖文件进页面即导入；MIDI 和同名音频自动配对；存在浏览器里下次还在；可导入整个文件夹 |
| 原曲伴奏 | 本地音频文件叠在底下播放，有对齐滑块 |
| 音色 | 钢琴（真采样）／八音盒／弦乐／长笛／电子琴；按住持续、松手止音、延音踏板 |
| 琴键尺寸 | 键宽、键高可调并记住；比屏幕宽时自动跟随滚动 |
| 输入 | 电脑键盘、鼠标、iPad 多点触控 |

### 2. 流水线脚本 `tools/`

**`B站转关卡.sh BV号 "歌名" [分P]`** —— 一条命令把 B 站视频变成关卡素材
```
yt-dlp 取地址 → 自动换 CDN 镜像下载（本地 IP 默认节点会 567 拒绝）
→ ffmpeg 转 audio/歌名.m4a                          ← 伴奏
→ Demucs 分离人声
→ basic-pitch 人声转 MIDI
→ 清洗：单声部 / 去弱音 / 八度纠错 / 去孤立杂音
→ midi/歌名.mid                                     ← 谱面
```
一首 4 分钟的歌约 1 分钟。音频已存在时跳过下载。跑完自动删中间文件。

**`打包曲目.sh`** —— 把 `midi/` + `audio/` 里的歌压进游戏 HTML（伴奏转 64kbps），打开游戏曲库里就有，不用拖。出新歌后跑一次。

**`安装转谱环境.sh`** —— 换电脑时运行一次。用 uv 拉独立的 Python 3.11（basic-pitch 不支持 3.13），不碰系统、不用 brew、不用 sudo。

## 三、决策与原因（以后别再纠结的）

- **为什么是网页不是 App**：iPad 和电脑要用同一个东西，网页一个链接搞定，双击 HTML 还能离线。
- **为什么键位不照钢琴键盘排**：目标用户不认琴键。按"这首歌用到的音"分配字母，7 个音就 7 个键，门槛最低。
- **为什么不转伴奏只转人声**：人声是单旋律，自动转谱最准；伴奏不用转，直接放原曲。谱和伴奏来自同一音频，天然对齐。
- **为什么原神两首不用 MuseScore 的谱**：要登录才能下，脚本抓不到。走音频转谱不依赖任何账号。想要更准的钢琴版可以自己注册试用下载，拖进曲库即可。
- **为什么放弃《层林尽染》**：BGM 工作室产物，没谱、不会有谱、纯器乐转谱效果差。
