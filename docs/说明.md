# 极夜落键 · 使用说明

## 切换歌曲 / 曲库

点底部「**曲库 · 切换歌曲**」。里面能看到所有歌，点「演奏」就切。

**7 首歌已经内置在游戏文件里**（标「内置」），打开就有，不用拖。
以后 `B站转关卡.sh` 出了新歌，运行一次 `./tools/打包曲目.sh`，新歌就进游戏文件；
在线版要重新发布一次才会更新。

往曲库里加歌的三种方式：
- 把 `.mid`（和音频）文件**直接拖进页面**任何位置
- 曲库里「添加文件…」多选
- 电脑上「导入整个文件夹…」选 `midi/`，一次全加进来

歌存在浏览器里（IndexedDB），下次打开还在；上次玩的那首会自动载入。
**同名**的 MIDI 和音频会配成一首歌（比如 `Nod-Krai.mid` + `Nod-Krai.m4a`），切歌时伴奏一起换。

`midi/` 里已经有：
- **Nod-Krai**、**To Light the Aeon Dark** — 从 B 站音频自动转的人声旋律谱，`audio/` 里有同名伴奏，一起拖进曲库就配对
- 5 首公版曲（致爱丽丝、卡农、月光、天空之城、River Flows in You），来自 bitmidi.com

## 怎么启动

**双击文件夹里的「双击开始玩.html」**，浏览器打开就能玩，**不需要网络**。
（联网时会多加载两个字体，没网就用系统字体，其他一切照常。）

## 导入一首歌：两条路

### 路 A · 有现成 MIDI（最省事，效果最好）

1. MuseScore / 弹琴吧 / MidiShow 搜歌名，下载 **MIDI**（不是 PDF）→ 放进 `midi/`
2. 想要原声伴奏：终端运行 `./tools/B站转关卡.sh BV号 "歌名"` → 音频进 `audio/`
3. 游戏里「载入 MIDI…」选谱子，「载入音频…」选伴奏，拖对齐滑块让落键和原声对上

原神、动漫、流行歌基本都有人扒好了 MIDI。先走这条路。

### 路 B · 只有 B 站视频，没谱

```
./tools/B站转关卡.sh BV1xxxxxxx "歌名"         # 每首歌一条命令
./tools/B站转关卡.sh BV1xxxxxxx "歌名" 2       # 多P视频取第2P
```

转谱环境**已经装好**（`tools/.tenv`，Python 3.11 + Demucs + basic-pitch，1.1 GB）。
以后换机器重装运行一次 `./tools/安装转谱环境.sh`。在终端里先 `cd ~/Desktop/极夜落键`。
一首 4 分钟的歌全流程约 1 分钟。

脚本做的事：下载音频 → Demucs 把人声从伴奏里分离出来 → basic-pitch 把人声转成单旋律 MIDI。
产物：`midi/歌名.mid`（旋律，你弹）+ `audio/歌名.m4a`（原曲，当伴奏）。
两个文件来自同一个视频，**对齐滑块保持 0 就是对的**，不用手调。

什么样的歌转得好：**人在唱、旋律清楚的**（AURORA 这种）。转得差：纯器乐带鼓带唢呐那种、说唱、和声多的。
转出来的谱不会完美，大概七八成准，用「等待我」模式先过一遍能听出哪里错。

## 免费 MIDI 资源（2026-11 核对过可访问）

知道歌名的话，先按这个顺序找：

**通用 / 流行 / 老歌**
- BitMidi — bitmidi.com — 免登录，10 万+，搜歌名直接下
- FreeMidi — freemidi.org — 按歌手分类
- MidiWorld — midiworld.com — 偏老歌、影视

**游戏 / 动漫**
- VGMusic — vgmusic.com — 游戏音乐老牌站，按平台/游戏分
- NinSheetMusic — ninsheetmusic.org — 游戏钢琴改编，PDF+MIDI，质量高
- Ichigo's — ichigos.com — 动漫钢琴谱+MIDI（核对时没打通，可能不稳）

**原神专属**
- Genshin Music — genshin-music.specy.app — 风物之诗琴社区谱库，能导出 MIDI。诗琴只有 21 个音，谱天生就是简化旋律版，最适合这个游戏
- MuseScore 搜「Genshin 歌名」— 最全，但下载多数要 Pro（7 天试用）

**中文站**
- 虫虫钢琴 gangqinpu.com — 中文歌最全，大多免费，有 MIDI 的会标出来
- 弹琴吧 tan8.com — 下载要琴币，签到能攒
- MidiShow midishow.com — 纯 MIDI 站，中文曲全，注册攒积分
- B 站搜「歌名 MIDI」「歌名 扒谱」— UP 主简介里常有网盘

**整包数据集**（一次几万首）
- Lakh MIDI Dataset「clean_midi」子集 — 1.7 万首按「歌手/歌名」命名的流行歌
- GiantMIDI-Piano（字节）— 1 万首古典钢琴
- MAESTRO — 古典钢琴演奏 200 小时

全编制 MIDI（十几轨带鼓的）也能用：游戏自动忽略鼓轨，「旋律」下拉框里手动挑人声/主旋律那一轨。

## 玩法

键位规则：**一首曲子用到几个音就只用几个键**。10 个音以内只用中间一排 `A S D F G H J K L ;`；
更多的话最常用的 10 个音放中间排，偶尔出现的高音在上排 `Q W E…`，低音在下排 `Z X C…`。落下来的方块上印着字母。

- **等待我** — 曲子停下来等你按对，不会失败。第一次摸新曲子用这个
- **跟节奏** — 只判定时机，按哪个键都出正确的音
- **照谱弹** — 键和时机都要对

不想被等：切到「跟节奏」或「照谱弹」即可，选择会记住。按错的键会红一下。

「键宽」「键高」按自己的手和屏幕调，会记住。琴键比屏幕宽时勾「跟随」自动滚。
`空格` 暂停。

## 音色与手感

- **钢琴是真录音**：Salamander Grand Piano（Alexander Holm，CC BY 3.0），每 3 个半音一个采样，29 个，压在游戏文件里（`assets/piano/`）
- **按住持续响、松手止音**，和真钢琴一样；低音衰减长、高音衰减短是录音自带的
- **延音踏板**：按住 `Shift`，或按住屏幕上的「踏板」按钮
- **力度**：电脑键盘没有力度；iPad 上按在琴键越靠下越响（库乐队的做法）
- 其他音色（八音盒 / 弦乐 / 长笛 / 电子琴）是合成的，弦乐长笛电子琴按住就一直响

琴键只是音高刻度，不代表乐器——笛子、人声、唢呐的旋律一样落在键上。滑音颤音会归到最近的半音，这是 MIDI 的共同限制。

音游刻意省掉的：多层力度采样、琴弦共鸣、半踏板、松键噪音。听不出来，体积却大十几倍。
